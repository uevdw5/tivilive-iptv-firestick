## How to install TiviLive on Firestick

TiviLive's current installation guide gives a dedicated Firestick procedure. It instructs users to enable **Install Unknown Apps**, install Downloader from the Amazon Appstore, enter the provider's supplied Downloader code, install the TiviLive APK and then sign in with the credentials from the welcome email.

The provider currently lists two Firestick app routes, including a primary TiviLive app and an alternative app. Its published instructions also say to delete the downloaded APK afterward to free storage space.

If you prefer using a player instead, the service's broader documentation references Xtream Codes credentials and M3U playlist URLs. TiviLive says both methods can load its channel and VOD catalog, while recommending Xtream Codes where available.

For troubleshooting, the provider recommends checking credentials carefully, restarting the device and router, reducing competing bandwidth usage, switching to Ethernet where possible, and testing other channels when only one stream is having trouble.

That last point is surprisingly useful. If one channel is buffering while another works normally, the Firestick is not automatically the culprit.
